# 3-minute demo (real records only)

Start from an empty database. Create every record live through the app right before recording.

| Time | Show |
|---|---|
| 0:00–0:20 | Problem: the same roads flood every monsoon; complaints are duplicated and unverified. |
| 0:20–0:50 | Citizen A (phone): Report → live camera with GPS accuracy → depth → submit → evidence checks → incident on the map. |
| 0:50–1:20 | Citizen B on the same road: “This problem may already be reported” → **I SEE IT TOO** → confirmation count rises, status becomes Verified. |
| 1:20–1:45 | Incident page: watermarked evidence, timeline, weather context and the explained risk level. |
| 1:45–2:05 | Safe route: “Lower-risk route — avoids 1 reported waterlogging zone, +N min”. |
| 2:05–2:40 | Ward officer: priority queue → create a work order for a worker → worker: on the way → in progress → done with GPS → citizens get “Work marked completed”. |
| 2:40–3:00 | A citizen taps **Still flooded** → incident reopens and the work record is kept. Close: one trusted incident instead of a hundred duplicate complaints. |
